# TTS Note

Android note-taking app with **text-to-speech** playback.

Built with Kotlin + Jetpack Compose. Notes are stored locally (Room). You can edit notes (Markdown-friendly UI) and play them back via a foreground TTS service with media controls.

## Features

- Note list + editor
- Local database (Room)
- TTS playback service (notification / media session)
- Light / dark / system theme
- **Language:** English (default) / 中文 — switch in the note editor settings sheet (tune icon → Language)

## Open in Android Studio

1. Open this folder as an Android Studio project
2. Let Gradle sync
3. Run on an emulator or device

## Stack

Kotlin · Jetpack Compose · Room · Android TTS
